# Wikipedia on the map

Every Wikipedia article near any place, as pins on a map. Click one to read it, or press **Surprise me**.

Live: https://luishae07.github.io/wikimap/

It is one static page. It asks Wikipedia's public API for articles with coordinates near the middle of the map, and shows the summary of the one you click. Map tiles © OpenStreetMap contributors, articles © Wikipedia (CC BY-SA). Map library: Leaflet.
